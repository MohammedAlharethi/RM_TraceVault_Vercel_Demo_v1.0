# طريقة رفع ديمو RM TraceVault على Vercel

1. أنشئ مستودع GitHub باسم `rm-tracevault-concept-demo` تحت حساب أو منظمة تملكها RM TraceVault.
2. ارفع جميع الملفات الموجودة داخل هذا المجلد إلى المستودع.
3. افتح Vercel واختر **Add New → Project**.
4. اربط حساب GitHub واستورد المستودع.
5. لا يحتاج المشروع إلى قاعدة بيانات أو متغيرات بيئة أو أمر بناء.
6. اترك Framework Preset على **Other**، ثم اضغط **Deploy**.
7. بعد النشر اربط نطاقًا تجريبيًا مثل `demo.tracevault.sa` من إعدادات Domains في Vercel.

## تنبيه

هذا الموقع ديمو تفاعلي ببيانات محاكاة. لا ترفع عليه أدلة حقيقية أو بيانات عملاء، ولا تستخدمه كمنصة إنتاجية.
